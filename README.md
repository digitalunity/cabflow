# Fitted furniture manufacturing operations website

Public website workbench for a fitted-furniture manufacturing operations platform.

## Naming status

**No public product name is currently locked.**

- **CabFlow** is retained only as an internal/historical working name because same-sector commercial use was identified.
- **DMMD** is retained only as a visual/mnemonic exploration for **Design. Manufacture. Manage. Deliver.** Existing commercial DMMD usage means it must not be treated as the selected public product/company brand.
- The final commercial word-name, public domain and trademark position remain unresolved.

The website should therefore remain brand-neutral until a candidate has passed the agreed ownership gate.

## Product category

**Fitted furniture manufacturing operations software**

The product spans:

- Design / configurable product definition
- Manufacture / production and machine outputs
- Manage / jobs, warehouse, finance and operational state
- Deliver / handhelds, scanning, offline delivery and field evidence

## Visual research

The DMMD concept produced useful visual ideas that can be reused after a valid name is selected:

- deep teal technical surfaces;
- bright green operational connection paths;
- large lifecycle typography;
- connected office, factory, warehouse and delivery imagery;
- module highlighting by capability.

These are design research, not a locked public identity.

## Public-content boundary

The public site must not depend on parent-company branding and must keep a clear distinction between:

- implemented product components;
- workflows and domain behaviour proven through reference implementations;
- planned product capability;
- future commercial direction.

Do not publish customer-specific data, internal network or architecture details, credentials, legacy weaknesses, or unverified SaaS claims.

## Development

The site is dependency-free static HTML and CSS.

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
